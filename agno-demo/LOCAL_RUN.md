# Kavoikoff&CO — запуск GPT-чата

Приложение содержит одного ИИ-помощника, обычную историю чатов и безопасное восстановление ожидающего ответа после обновления страницы.

1. Добавьте `GROQ_API_KEY` в Codespaces Secrets или переменные среды сервера.
2. Бесплатный план использует `openai/gpt-oss-20b`, Pro — `openai/gpt-oss-120b`. Модели можно изменить через `GROQ_FREE_MODEL` и `GROQ_PRO_MODEL`.
3. Из корня репозитория запустите `bash agno-demo/start.sh`.
4. Откройте порт `4173` в разделе Ports.
5. На iPhone откройте ссылку в Safari и выберите «На экран Домой».

История хранится локально на сервере в `agno-demo/data/chats.db` и не попадает в Git. Старую базу двух агентов приложение не удаляет и не показывает.

По умолчанию Free получает 10 сообщений в сутки, Pro — 200. Лимиты меняются переменными `FREE_DAILY_MESSAGES` и `PRO_DAILY_MESSAGES`. Идентификатор установленного приложения хранится на устройстве, а сервер сохраняет только его SHA-256-хеш. Для публичного платного запуска следующим этапом подключаются учётные записи и платёжный webhook.

Если ответ не появился после обрыва связи, нажмите «Проверить ответ». Один и тот же запрос автоматически повторно не отправляется.

`GROQ_API_KEY` нельзя помещать в JavaScript, HTML или коммиты. Ключ используется только серверной частью.
