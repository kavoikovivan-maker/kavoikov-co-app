# Kavoikov&CO — восстановление

Это исправленная копия приложения. Она ещё не установлена в вашем Codespace.

1. Сохраните прежнюю папку agno-demo как резервную копию. Остановите только старый pwa_server.py на порту 4173.
2. Распакуйте содержимое папки agno-demo из этого архива поверх существующей agno-demo. Виртуальное окружение и скачанную модель оставьте на месте.
3. Если существующая рабочая история находится в pwa/discussions.db, она будет скопирована через SQLite Backup в data/discussions.db при первом запуске. Если рабочей базы нет, используется приложенная discussions.backup.db. Если data/discussions.db уже существует, она не перезаписывается.
4. В терминале запустите bash agno-demo/start.sh из корня проекта. Скрипт не вызывает модель. При отсутствующих Python-зависимостях он их устанавливает. Ollama и модель автоматически не скачиваются.
5. В Ports откройте порт 4173 с видимостью Private. Войдите в GitHub в Safari. Обновите страницу, затем закройте и снова откройте приложение. При старой иконке удалите только ярлык с Домой и добавьте заново.

Если приложение недоступно: убедитесь, что Codespace запущен; проверьте data/server.log и data/ollama.log. Не меняйте порт на публичный. База, история и секреты не должны попадать в Git.

Запрос сразу получает номер задания. Автор и Критик работают в фоне последовательно, интерфейс проверяет результат короткими GET-запросами. После перезагрузки повторной генерации нет. Если связь потеряна, нажмите «Проверить ответ». Если сервер перезапустился в процессе, задача помечается ошибкой, без автоматического повтора. Уже полученный ответ Автора сохраняется в записи задания.

Модель работает на Codespace, не внутри iPhone. Бесплатный локальный API не отменяет лимиты времени и хранения GitHub. Для экономии останавливайте Codespace после использования; сервер и ответы тогда недоступны.

Проверки этого пакета выполнены без реальных вызовов модели. Качество ответов qwen2.5:3b не гарантируется. История прежней версии содержит только Автор/Критик: отсутствующие старые реплики пользователя восстановить нельзя. Новые реплики пользователя сохраняются.
